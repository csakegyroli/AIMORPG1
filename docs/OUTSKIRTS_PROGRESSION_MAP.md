# AIMORPG OUTSKIRTS — PROGRESSION MAP
## Draft v0.1
**Status:** PHASE 1 PROPOSAL — CENTRAL REVIEW REQUIRED

## 1. Constraints
- No energy system.
- No daily mandatory tasks.
- No forced real-time waiting.
- No Pay-to-Win.
- No single mandatory progression path.
- Global character XP/levels/stats stay central.
- The 60 main quests remain unchanged.
- Optional district progression cannot gate main story progression.

## 2. Progression layers

### Layer A — Global character progression (central)
Existing player level, XP, development points and stats. Districts may use approved stats as prerequisites/modifiers but cannot create global stats or award unapproved XP.

### Layer B — NPC relationships (shared)
Use existing relationship facets, aggregate values, NPC runtime. No district-specific parallel reputation meter.

### Layer C — Knowledge/mastery (proposal)
Optional capability-based advancement records for professions and activity families. It should unlock decisions, recipes, routes, cases or techniques—not only passive numerical inflation.

Possible families:
- Craft mastery: weaponsmithing, armorsmithing, leatherwork.
- Trade knowledge: appraisal, bargaining, ingredient assessment, accounting.
- Underworld knowledge: source verification, card strategy, contact access.
- Civic knowledge: document analysis, evidence handling, patrol planning.
- Exploration knowledge: ingredient analysis, ruin methods, puzzle techniques.

Open decision: common mastery contract versus district-specific records behind one shared progression interface.

### Layer D — Discovery and access (shared state)
Optional discoveries, maps, verified leads, credentials, expedition completion and authored Eye observations. Use shared world/narrative state and preserve Canon.

### Layer E — Equipment and preparation (shared)
Equipment instances, consumables, recipes, repair and proposed enhancement are shared. No district-specific power model.

## 4. Cross-district loops
1. Pell/Zora ingredients → Eldra research → Workshop recipe/material application.
2. Petar/Damar deliveries → Old Market supply → Cador transaction records → Watch investigation.
3. Miri intelligence → Rovan optional case → Lena document authentication → Bran/Orren follow-up.
4. Jarek maps → Siven expedition → Maela clue → A Szem authored observation.
5. Workshop preparation → Siven expedition readiness → discovery/material reward.
6. Vera coin inspection → Cador records → Miri source network, with Black Coin Canon untouched.

## 5. Pacing principles
- Unlocks follow demonstrated actions and knowledge.
- No daily repetition.
- No forced offline timer.
- Repeatable activities have bounded, economy-reviewed rewards.
- Failure may provide learning or partial progress where appropriate.
- Avoid erasing long-term progress for a single failure.
- Important objectives should support alternate approaches.
- Relationship access may open opportunities but should not gate all progression behind one NPC.

4. Enhancement/stat scaling.
