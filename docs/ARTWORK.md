# AImorpg – Artwork Pass v0.14

## Irány
A demo vizuális nyelve: sötét fantasy, bronz/arany keretek, festett helyszínképek, karakterközpontú UI és finom fény/glow rétegek.

## Beépített artwork
- `capital-map-v2.webp` – új, részletes fővárosi térkép
- `market-art-v3.webp` – Kereskedelmi Központ illusztráció
- `capital-map-v2.webp` – új fővárosi térkép artwork

## Következő grafikai kör
1. Egyedi, különálló portré minden kiemelt polgárnak.
2. Külön nappali/éjszakai artwork minden nyitott városrészhez.
3. Ünnepi/fesztivál overlay-ek rétegenként.
4. Teljes item ikoncsomag egységes kerettel és ritkasági nyelvvel.
5. A Szem végleges, transzparens emblémája.
6. Királyi palota, aréna, kikötő és külváros egyedi belső jelenetei.
