# AI Council Handoff Checklist v1.0

The AI may be enabled only when all validators are available.

### Inputs
- Player identity snapshot
- Relationship facets and interpreted states
- World memories and recent dynamic events
- NPC runtime states and schedules
- Active main quest and Quest DNA
- Regional access and current region
- Item catalogue and current inventory/material counts
- Market demand/economy snapshot
- Eye observations
- Candidate opportunities, dialogue pressure and world event candidates

### Outputs
- Structured SideQuestBlueprint proposal
- Structured dialogue response proposal
- Structured WorldEvent proposal
- Economy pressure/market recommendation

### Validation gates
Canon → NPC → World → Item → Relationship → Timeline → Consequence

### Forbidden
- Direct code generation
- Direct UI mutation
- Canon invention
- New item IDs not in catalogue
- New NPCs without content authorization
- Teleporting the player
- Rewriting completed main quests
- Hidden currency/item creation
- Repeating the same story signature for the same player/NPC without a new state trigger
