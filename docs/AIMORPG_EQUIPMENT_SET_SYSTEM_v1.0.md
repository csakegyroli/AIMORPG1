# AIMORPG Equipment Set System v1.0

## Core rule
A set is a five-piece regional collection: weapon, shield, armor, gloves (internally `accessory`), and boots.

Every capital region has three distinct sets: Common, Rare, Legendary. Each rarity is a separate set identity and may not mix for bonuses.

## Regional identities
- Külváros: Ügyesség + Árnyék
- Aréna: Harc
- Kereskedelmi Központ: Kereskedelem
- Belváros: Társas
- Palota: Tudás
- Kikötő: Harc + Ügyesség + Árnyék

## Acquisition
- Common: sold by local merchants through regional markets.
- Rare: future side-quest rewards; not market-eligible.
- Legendary: future high-impact side-quest/story rewards; not market-eligible.

## Set progression
Equipping 2 pieces activates the first set bonus, 3 pieces the second, and all 5 pieces the final full-set bonus. Bonuses add to effective player stats.

## Narrative role
Set pieces are designed to become future quest hooks, NPC rewards and regional identity anchors. Quest and side-quest content must reference specific pieces or sets only through the canonical item IDs.
